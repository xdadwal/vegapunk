Screenshots of the Vegapunk web interface (dark theme, 1440x900 at 2x), used in the project README.
They were taken from a throwaway demo instance watching sample containers (`web`, `db`, `cache`, `worker`, and a deliberately failing `jobs`). The Containers list and the demo frames also show the real `vegapunk` container (the maintainer's own instance) and `vpdemo-vegapunk-1` (the demo instance itself); the agent answer is real (Gemma via Docker Model Runner), and the three findings are sample rows added to the demo database for illustration.
To regenerate, run a demo instance and then `capture.mjs` from a directory with `playwright` installed (see the usage comment at the top of the script; credentials come from `VP_USER` and `VP_PASS`).

`demo.gif` is a 24-second walkthrough recorded the same way (1280x720 frames, scaled to 960x540): Overview, Containers, the `jobs` container, Findings, the restarting finding, then asking the agent about it. The agent's answer is real (Gemma via Docker Model Runner); the minute or so it spent working is cut, and a caption frame says so.
To regenerate, run `make-demo.mjs` against a demo instance (usage at the top of the script; `VP_QUESTION` replaces the suggested question before sending), then `python3 make-demo.py <frames dir>` (needs Pillow) to write `demo.gif`.
