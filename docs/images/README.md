Screenshots of the Vegapunk web interface (dark theme, 1440x900 at 2x), used in the project README.
They were taken from a throwaway demo instance watching sample containers (`web`, `db`, `cache`, `worker`, and a deliberately failing `jobs`); the agent answer is real (Gemma via Docker Model Runner), and the three findings are sample rows added to the demo database for illustration.
To regenerate, run a demo instance and then `capture.mjs` from a directory with `playwright` installed (see the usage comment at the top of the script; credentials come from `VP_USER` and `VP_PASS`).
